| Zod | MIT — [upstream](https://github.com/colinhacks/zod) |

The table is a component summary. Complete license and copyright texts ship in `Contents/Resources/THIRD_PARTY_NOTICES.txt`, generated by `scripts/bundle-notices.mjs` during desktop preparation. It includes installed production npm dependencies, the resolved Rust dependency graph for the target platform (including build helpers, excluding development-only dependencies), Node's bundled-component notices, and the whisper.cpp runtime license. Missing required license text stops packaging; upstream license alternatives and original notice contents are preserved.

The verified 0.1.0 arm64 app contains the combined notice file with 101 npm package sections and 266 Rust dependency sections, plus Node and Whisper notices. Its contents matched the generated source artifact. These counts describe that build; regenerate notices after changing dependencies or target architecture.

Separate `NODE-LICENSE` and `WHISPER-LICENSE` files also ship in `Contents/Resources/bin/`. Model weights download on demand and are not included in the app or DMG. Apple system frameworks are supplied by macOS. Development-only tooling retains its notices in the installed packages and source checkouts.
